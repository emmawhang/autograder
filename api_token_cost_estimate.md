## Assumptions and Edge Cases

- One successful `POST /grade` request makes one application-level call to `chat.completions.create`; there are no application retry loops or multi-turn calls.
- Input tokens are estimated as `round(characters / 4)`, including the strict system prompt and the constructed user prompt. The estimate averages 10 notebook sample(s): `submission_tests/*.ipynb` when present.
- The sampled student payload averages 1,137 characters; the prompt also includes the full assignment (7,230 characters), rubric JSON, grading rules, and extracted cell outputs. Actual usage varies with code, markdown, and output length.
- Output is modeled at 600 tokens for JSON grading breakdown plus final feedback. The code does not set `max_tokens`; measure `usage.completion_tokens` in production for billing accuracy.
- Pricing defaults to OpenAI `gpt-4o-mini` standard rates of `$0.15/1M` input and `$0.60/1M` output tokens (see [OpenAI API pricing](https://openai.com/api/pricing/)). Override with `INPUT_PRICE_PER_MILLION`, `OUTPUT_PRICE_PER_MILLION`, and `OUTPUT_TOKENS` if using another provider/model.
- The OpenAI SDK can retry some transient failures internally. This report excludes failed/retried requests; multiply by the observed request-attempt factor if provider logs show retries. A failed request may still be billable depending on provider behavior.
- Cached-input discounts, batch pricing, taxes, credits, rate-limit fees, and provider-specific free tiers are excluded.
